# CottageThermoESP V1.0.4 — 60-second LAN-first recovery test build

**Field-test firmware; not yet approved for unattended installation.**

## What changed
- On a failed read-only `/api/link` LAN status probe, continue attempting Wi-Fi/LAN for up to 60 seconds before trying ESP-NOW. The interval is measured across normal status polls; there is **no blocking one-minute request**.
- If any authenticated LAN status reply (or acknowledged normal temperature report) succeeds, clear the recovery window and continue on LAN.
- If the room thermostat truly loses Wi-Fi, retain the existing immediate ESP-NOW fallback path.
- If LAN remains unavailable for 60 seconds, try the existing encrypted ESP-NOW fallback. Continue to prefer LAN when it recovers.
- Expose grace starts, recoveries, expirations, deferred-probe counts and remaining time in read-only link diagnostics. V1.0.3 learning diagnostics remain available.

## Explicit safety boundaries
- No change to controller firmware, servo PWM, movement, calibration, TL wire protocol, target setpoint or existing 30-minute controller loss watchdog.
- No extra retry of an ambiguous target/Away command. These operations return a failure to the UI if the fresh required preflight status cannot be obtained. User can retry deliberately.
- No queue of stale temperature values: the SHT45 task naturally produces a fresh value every 15 seconds. A missed sensor sample is reported as unacknowledged and the next fresh sample is sent after connectivity returns.
- Existing TL 5-second authenticated command lease, sequence checks, temperature-validity checks and ESP-NOW key authentication remain unchanged.
- A disconnected panel can use ESP-NOW immediately (the one-minute grace is for LAN failures when the panel still has Wi-Fi).

## Verification
Run host policy and diagnostic tests, web tests, and IDF firmware builds. Install only the thermostat application image while onsite. The controller firmware is not changed. During normal heat cycles compare the `/api/controller/diagnostics` counters (LAN grace starts, recovered and expired; ESP-NOW switches) before/after. Download diagnostics and learning CSV before reboot.
