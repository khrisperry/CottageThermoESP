# CottageThermoESP V1.0.2 — Passive learning field-test update

This field-test candidate improves the **read-only** collector introduced in V1.0.1. Thermostat control policy, current controller firmware, and the ESP-NOW command protocol remain unchanged. Automatic thermal learning/trim stays disabled.

- Preserve controller's actual fractional commanded positions. Quarter-step (0.25 dial) provisional bins now include positions such as 2.727.
- Include `mean_commanded_level` in learning summaries to distinguish exact observed positions from rounded bins.
- Record numeric electrical watts/amps whenever available, separately from learning eligibility.
- Add `monitor_enabled`, `installed_at_cottage`, and current freshness diagnostics to exported CSV.
- Keep 90-minute unchanged-command, valid encoder/Live, fresh weather and onsite power safeguards for provisional model eligibility.
- Model schema 2 resets any previous schema-1 candidate summary; no controller/servo calibration is touched.

Build/test results must be verified before OTA, and field tests must be performed at the furnace. See [docs/PASSIVE_LEARNING.md](../PASSIVE_LEARNING.md).
