# CottageThermoESP V1.0.1 — Passive learning candidate

This is a review-only field-test build of the Waveshare ESP32-S3 Touch-LCD-4B thermostat. **No automatic learning changes the furnace dial or calibration.** The controller firmware and ESP-NOW protocol remain functionally unchanged.

- Five-minute room sensor, controller status, furnace electrical power and outdoor weather snapshots.
- Read-only controller LAN status (commanded dial, AS5600 angle, Live state, target); ESP-NOW-only links are noted as missing detailed readback.
- CSV export at `/api/learning.csv`, status at `/api/learning`, and a Learning tab in thermostat settings.
- Stable-window advisory half-dial averages for manual review; summary checkpoints to a separate NVS namespace, without changing calibration.
- Seven days of volatile CSV ring in PSRAM, 24 hours fallback; download before reboot.

Before deploying unattended, validate the installed equipment onsite with the field-test plan in [docs/PASSIVE_LEARNING.md](../PASSIVE_LEARNING.md). ESP-IDF compilation and CI tests are not a physical safety validation. Leave automatic trim disabled and do not extend the permitted servo travel.
