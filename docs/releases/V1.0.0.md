# CottageThermoESP V1.0.0

First coordinated V1.0.X release for the HW-747 Super Mini furnace controller and Waveshare ESP32-S3 Touch-LCD-4B thermostat, based on the working controller 0.7.5 / thermostat 0.15.4 baseline.

- One root VERSION drives both firmware versions, boot logs and status reporting.
- Persistent Live starts from the measured fractional dial position; calibration/expected angles are visible, and Capture replaces a marking's saved pulse/angle.
- Includes stable encoder startup, magnet-loss pause/recovery, servo verification and persisted fault diagnosis.
- Includes LAN/mDNS and paired encrypted ESP-NOW recovery, native display pages, temperature offset, HA/MQTT Climate, furnace power monitoring and outdoor weather.
- Root build defaults select the actual Super Mini and 4B boards. Unknown PowerShell switches fail clearly. Existing board helpers remain supported.
- Fresh room configurations select SHT45/SHT4x on SDA47/SCL48; saved local sensor settings remain in effect.
- Consolidated CI builds and per-device packages include version/identity validation, manifests, SHA-256 checksums and flash instructions.

Application names, partition offsets, NVS formats, calibration and pairing are unchanged. Normal upgrades preserve saved settings. Controller updates use USB; room-panel application OTA remains supported. Use single-dash `-Flash -Monitor` switches and the actual device COM ports. See [the production guide](../PRODUCTION.md).

Automatic thermal learning and overshoot trim remain disabled. This release consolidates the bench-tested baseline; final installed furnace validation is separate.
