# CottageThermoESP V1.0.3 — LAN/ESP-NOW diagnostic build

Diagnostic field-test build; not promoted to production.

- Captures read-only learning status GET errors separately from normal controller link HTTP requests.
- Records actual transport switch events, mDNS problems, Wi-Fi association/RSSI/channel and HTTP timing in a bounded in-memory ring.
- Adds Settings > Link diagnostics and read-only /api/controller/diagnostics JSON download.
- Appends learning_lan_reason and selected_control_transport to the learning CSV.
- Includes host tests for diagnostic counters and event coalescing.
- Does not alter Wi-Fi preference, ESP-NOW fallback behavior, controller firmware, servo control, saved calibration, or learning eligibility.

See docs/LINK_DIAGNOSTICS.md for instructions. Save JSON and CSV before reboot: traces are RAM-only.
