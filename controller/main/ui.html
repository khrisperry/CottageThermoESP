Thermostat settings

The furnace’s own thermostat cycles the heat. This controller maps your target to a measured dial setting. Level 0 is excluded.

Calibration & position

Enter 2–8 measured points in increasing temperature and dial order. Pulse widths must stay between 1100 and 1900 µs and move consistently in either direction. The controller never extrapolates.

Synchronization does not move the servo. In simulation this establishes a virtual starting point; in live bench mode it is your observation, without encoder verification. Reboot, map change, Manual or Stop clears it.

Weekly schedule

Use up to 14 entries. days is a bit mask: Mon=1, Tue=2, Wed=4, Thu=8, Fri=16, Sat=32, Sun=64; every day=127. minute is minutes after midnight. The latest entry carries forward, including across Sunday/Monday.

Time zone: Detroit, including daylight saving time. LAN mode synchronizes time with NTP. After an AP-only cold boot, set the clock here. An unavailable clock blocks scheduled movement. Setting a target manually disables the schedule until you enable it again.

Choose control mode

Test mode stops PWM and enters Hold. Thermostat mode restores automatic control selection, but existing safety interlocks still apply.

Attended servo position test

Raw PWM is physical, including in simulation firmware. Remove the load; arm explicitly for 15 minutes. Testing commands require Hold mode. Never send new positions automatically on page load.

Pulse range: 500–2500 µs. Jog changes the pulse by 10 µs, then sends a physical PWM command only when the bench arm and Hold safety checks pass.

Observed dial level & synchronization

This records the dial level you observed. It does not move the servo or calculate the dial level from the encoder.
