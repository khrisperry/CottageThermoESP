Reading saved mode…

Live starts only after calibration, fresh thermostat samples and calibrated AS5600 position validation. Test/Service stops automatic movement.

Live selection survives power loss. On reboot PWM remains OFF until encoder and sensor checks pass. An encoder or PWM fault stops movement and selects Service. The controller remains heat-only and should be physically validated before leaving unattended.

01 / Find the travel

Set start & end positions

Enter Test Mode, then move in small steps using the movement controls. At each end of the usable travel, capture the current position. Stop short of binding or a mechanical stop.

START LIMITNot set
END LIMITNot set

Once both limits are saved, every movement is restricted to that range. Use Re-measure if a limit was set too early; other dial positions and temperature estimates are preserved.

01 / Mark the dial

Save each knob position

Jog to each marking, then click Capture. Positions are saved immediately. The angle is recorded when the encoder reading is valid.

Off and Max are reference positions. Go uses only the numbered settings 1–6. Captured angles are a reference; the controller does not yet correct movement using encoder feedback.
02 / Give the dial meaning

Estimated temperature at each number

What room temperature does each furnace setting roughly maintain? Start with estimates and refine them after installation. Values must increase from 1 to 6.

These are estimates of the furnace’s own thermostat setting. Go selects a dial setting for your target temperature; the furnace still cycles the heat.
03 / Check physical movement

Test Mode

Automatic control is disabled. You move the arm deliberately using small jogs or a saved dial position.

  1. Click Enter Test Mode in the movement controls.
  2. For the first move, enter a known starting pulse and click Move to starting pulse.
  3. Use − / + to make small adjustments. Watch the live angle and arm.
  4. Check saved positions below. Finish at a numbered position before Go.
04 / Let the thermostat drive

Bench Go or Persistent Live

From Test Mode, move to the selected saved numbered dial position. Bench Go lasts 15 minutes. For a final installed and verified furnace, select persistent Live above; it resumes after reboot only when the calibrated AS5600 position and fresh sensor validate.

    Checking setup…Bench Go: 15-minute attended session. Live: persistent selection and no bench timer; every movement is checked against the encoder. Boot starts electrically stopped until verified.
    Heat response: observe the room after each setpoint change. Sustained +2°F overshoot can command a small downward trim after settling. Recorded estimates are never silently rewritten.
    Move to the selected number while in Test Mode. Verify the arm matches that marking, then press Go.

    A thermostat setpoint moves promptly to its calibrated dial position (2-second anti-chatter guard). Heat-only feedback waits at least 10 minutes after the setpoint, then requires +2°F overshoot for 5 continuous minutes before trimming down 0.25 dial; further trims are spaced by 15 minutes. This is a provisional learning rule: saved estimated temperatures are not rewritten without validating real furnace cycles. A stale sensor, incomplete calibration, expired bench session or servo fault blocks motion. Physical position remains unverified by the AS5600.
